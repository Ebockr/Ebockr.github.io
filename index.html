Research

Learning from Human Interventions: Intervention Inverse Reinforcement Learning

Bachelor thesis, Learning & Adaptive Systems Group, ETH Zurich, 2026. Grade: 6.0/6.0. Supervised by Andreas Krause, Thomas Kleine Buening, and Bruce D. Lee.

Can an agent recover near-optimal behavior from nothing but stop-signal interventions, supervisor occasionally halting it? I formalized several intervention rules in finite-horizon MDPs, analyzed what each reveals about the latent reward, and proved reductions between them. Building on this, I developed an inverse-RL algorithm that updates a feasible set of rewards from intervention feedback, with termination and sub-optimality guarantees, and validated it in gridworld experiments.
